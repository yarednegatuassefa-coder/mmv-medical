## Purpose
Re-engage patients who have not responded.
This is a continuation of guidance, not a sales chase.

## Follow-up sequence
- Day 3: Soft check-in — educational angle, no pressure
- Day 7: Share something relevant — article, success story, FAQ
- Day 14: Final gentle touch — leave door open
- Day 30: Close the sequence — log in Supabase as cold

## Message principles
- One message per follow-up, never two in a row
- Always add value — never just "checking in"
- Match the language of the patient's last message
- Never mention competitors
- Never create urgency that doesn't exist

## Reply classification
When a patient responds, classify as:
- POSITIVE → escalate to Jared for booking
- NEUTRAL → answer question, offer next step
- OBJECTION → run competitive rebuttal skill
- OOO → reschedule follow-up to day+7
- NEGATIVE → close sequence, log in Supabase

## Never do
- Send a follow-up if patient said they are not interested
- Follow up more than 3 times without a response
- Mention price in a follow-up message
- Follow up on weekends for UK/NL patients
