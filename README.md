# MMV Medical

MMV Medical is an international healthcare and medical-tourism information and patient-coordination project.

## Project governance

Read [AGENTS.md](AGENTS.md), [CLAUDE.md](CLAUDE.md), and [failures.md](failures.md) before patient-related work.

The project follows the portfolio [Workflow Quality and Evaluation Standard](https://github.com/yarednegatuassefa-coder/home/blob/main/standards/workflow-quality.md). Its local [workflow governance and evaluation plan](docs/workflow-governance.md) defines the initial lead-intake, patient-coordination, communication, review and measurement requirements.

## Safety

- No clinical decisions or diagnosis by AI.
- No final treatment prices or plans without appropriate human/clinical review.
- No patient-facing messages or CRM writes without the required approval gate.
- Never expose patient identifiers, health details, medical records, passport data or private communications to external agents or telemetry.
- Use synthetic fixtures for testing and evaluation.

This README is a navigation entry, not a statement that every workflow is implemented or production-ready.
